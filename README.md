# smell-legal

Documentos legais públicos do app **Smell** (o diário olfativo).

- **Política de privacidade:** https://pdellamore.github.io/smell-legal/privacy.html
- **Termos de uso:** https://pdellamore.github.io/smell-legal/termos.html

A raiz (`https://pdellamore.github.io/smell-legal/`) redireciona para a política, porque é
o endereço já registrado no App Store Connect.

A fonte de verdade é `legal/privacy.html` e `legal/termos.html` no repositório do app —
este repo é só a publicação. Mudou o que o app coleta, a política muda junto; mudou o
direito sobre o que ele coleta, os termos mudam junto.
